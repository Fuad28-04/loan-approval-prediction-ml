# Loan Approval Prediction Using Machine Learning

## Overview
A binary classification model that automates loan approval decisions by analyzing applicant financial and personal data.

## Problem Statement
Help financial institutions make faster and more accurate lending decisions by predicting loan approval outcomes.

## Dataset
- 630,000+ data points
- 14 features including credit score, income, employment experience, and loan default history

## Key Findings
- Previous loan defaults showed strongest negative correlation with approval
- Credit score and interest rate were significant predictors
- Dataset was imbalanced (more denials than approvals)

## Models Used
- Binary Classification with ML algorithms
- Correlation analysis via heatmap
- Class imbalance handling

## Technologies
- Python
- Scikit-learn
- Pandas, NumPy
- Matplotlib, Seaborn
